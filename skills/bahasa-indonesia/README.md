# bahasa-indonesia

Force Indonesian responses. Caveman-ultra style preserved.

## What it does

Switch AI output to Bahasa Indonesia while keeping caveman compression active. Technical terms stay English. Code blocks unchanged. Auto-detects when user writes in Indonesian.

## How to invoke

```
/bahasa
```

Also triggers on:

- "pakai bahasa indonesia"
- "jawab indonesia"
- "respond in indonesian"
- "gunakan bahasa indonesia"

## Deactivate

```
stop bahasa
english mode
pakai english
```

## Example

```
User: Kenapa API return 500?

Response: Error di handler. Null ref → crash. Tambah guard clause sebelum akses `.data`.
```
